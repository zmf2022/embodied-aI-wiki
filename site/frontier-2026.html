AGENTIC ROBOT LEARNING / NO LOWER-BODY REQUIREMENT

建议以现有药房补药、样本库任务为研究场，构建 Codex/Claude 主动探索、技能代码改进、BC/RL/VLA 后训练、独立评测的分层闭环。Figure 的陌生环境泛化指标可作为评测原则，而不是增加人形运动研发负担。

Agent 自动构建任务与仿真

实验治理

自动研发的 Agent 不得修改验收规则、冻结测试集或机器人安全边界；训练输出先在仿真中审查，真机执行需要额外的权限、安全检查和人工可回滚控制。推理阶段技能编排与训练阶段改权重分开审计。
